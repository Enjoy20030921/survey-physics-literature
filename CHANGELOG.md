# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-15

### Added

- Multilingual Codex Skill triggers for Chinese and English physics literature-review requests.
- Protocol-driven review gates for HEP and `gr-qc` research.
- Deterministic arXiv, INSPIRE, and Crossref retrieval, normalization, caching, and deduplication.
- Title/abstract screening, lawful full-text retrieval, citation expansion, and provenance tracking.
- Locator-backed evidence records and citation-audit requirements for substantive claims.
- Chinese, English, and independent bilingual XeLaTeX/BibTeX report modes.
- Stable identifiers and incremental-update support for existing reviews.
- Offline regression tests, validation scripts, and adaptive report templates without a fixed chapter outline.
- Complete English and Simplified Chinese project documentation.
